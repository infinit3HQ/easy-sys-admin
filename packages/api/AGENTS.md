# AGENTS.md: packages/api

`openapi.yaml` is the contract of the control plane API under `/api/v1`. Three things are generated from it: the Go server interface (`apps/esa/internal/api/api.gen.go`), the Go client the CLI uses (`apps/esa/internal/apiclient/client.gen.go`), and the TypeScript types (`src/schema.gen.ts`). The web app and the MCP server import those types through `src/index.ts`. Change the spec first, then the code. Never edit a generated file.

## Workflow

1. Edit `openapi.yaml`.
2. Run `pnpm generate` at the repo root. Turborepo runs `openapi-typescript` here and `go generate ./...` in `apps/esa`.
3. Run `pnpm --filter @esa/api lint` (Redocly, then ESLint).
4. Implement the Go handler in `apps/esa/internal/api`. `var _ StrictServerInterface = (*Handlers)(nil)` in `handlers.go` must compile, so every operation needs a method. Put the logic in `fleet`, not in the handler.
5. Use the new types in TypeScript. Common ones are re-exported by name from `src/index.ts` (`Server`, `Group`, `Run`, ...). Add an export there when a type is used in many places. For the rest, use `Schemas['X']`.
6. Commit the generated files. CI regenerates them and fails on any diff.

```sh
pnpm generate
pnpm --filter @esa/api lint
pnpm --filter @esa/api typecheck
```

## Conventions

### Operations

- `operationId` is lowerCamelCase, verb first: `getX`, `listX`, `createX`, `updateX`, `deleteX`, or a plain verb for actions (`startRun`, `acceptHostKey`, `switchAccount`, `testChannel`). It becomes the Go method name and the CLI client method.
- Give each operation a one-line `summary` and one tag from the list at the top of the file: `session`, `fleet`, `servers`, `server-live`, `groups`, `runs`, `alerts`, `settings`, `teams`, `sharing`. Add a tag there before you use a new one.
- Every operation ends with `default: { $ref: '#/components/responses/Error' }`.
- Status codes: `200` for reads and updates, `201` for creates, `202` for work started in the background (`startRun`), `204` for deletes with no body.
- Public operations set `security: []`. Everything else inherits the session cookie or bearer token.
- Request bodies set `required: true` and point at a named schema.

### Errors

- One shape: `{"error": {"code": "...", "message": "...", "field": "..."}}` (`Error` and `ErrorDetail`). `field` is set only for `bad_request` about one input.
- Codes: `bad_request` (400), `unauthorized` (401), `forbidden` (403), `not_found` (404), `conflict` (409), `unavailable` (502, and 504 on timeouts), `internal` (500). `apps/esa/internal/api/handlers.go` maps fleet errors to them.
- Do not add per-operation error schemas.

### Schemas

- Name schemas in PascalCase. List responses are `XList` objects with a required `items` array, never bare arrays.
- List every property that is always present in `required`. Generated Go and TypeScript types make the rest optional (pointers in Go, `?` in TypeScript).
- Mark properties that can be `null` with `nullable: true`. The spec is OpenAPI 3.0.3, so no `type: [x, 'null']`. The Go codegen uses `nullable-type: false`, so nullable fields are pointers.
- ids are `type: integer, format: int64`. Path ids reuse `components/parameters` (`ServerId`, `GroupId`, `ChannelId`, `UserId`) where one exists.
- Timestamps are `type: string, format: date-time`.
- Closed sets are `enum`s, either inline or as a named schema (`Role`, `Scope`, `RunKind`).
- Types shared with `esa-helper` map to Go with `x-go-type: proto.X` and `x-go-type-import` for `.../internal/hostops/proto`. Keep the YAML fields in step with the Go struct.
- Describe fields whose meaning is not obvious from the name with `description`.
- Secret-bearing path segments use `maxLength: 128`, like `LinkToken`.

### Lint

- `redocly.yaml` extends `recommended`. It turns off `no-server-example.com` (the server URL is the relative `/api/v1`) and `operation-4xx-response` (public endpoints have no error response), and makes `no-empty-servers` an error.
- Lint must pass with no errors. It shows 9 warnings today: 7 tags without a description, a license without a URL, and one `$ref` with sibling keys. Do not add more. Give new tags a `description`.

## Files

- `openapi.yaml`: the contract.
- `src/schema.gen.ts`: generated by `openapi-typescript`. Do not edit.
- `src/index.ts`: `createApiClient`, the `Schemas` alias, and named type exports.
- `redocly.yaml`: lint rules.
