# Security policy

Please do not open a public issue for a security problem. Open a private security advisory on the GitHub repository instead: the Security tab, then "Report a vulnerability". Include what you found, how to reproduce it, and the commit you tested.

Only the latest commit on `main` gets fixes.

The security model is described in [docs/security.md](docs/security.md), and what esa may do on a managed server in [docs/server-helper.md](docs/server-helper.md).
